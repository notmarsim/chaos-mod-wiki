# Bem-vindo ao Chaos Mod

[English](../en/index.md)

Chaos Mod combina uma árdua progressão de máquinas com exploração dimensional perigosa. Construa uma fonte de energia, refine materiais, automatize a manutenção e alcance uma infraestrutura que permita viajar para as Realities.

As Rifts apresentam essas dimensões bem antes: anomalias temporárias trazem terreno e criaturas tierizadas para o Overworld. Você pode fechá-las para conseguir materiais ou deixá-las ativas para combate e farm, com uma pequena chance de evoluírem para uma Dimensional Breach.
