# Empowered Flux Crystal and station transfer performance

The manual station inventory now invalidates its recipe cache without resolving recipes on each slot edit. The menu resolves the final output before broadcasting, and the machine tick also refreshes it. Taking output always validates current inputs. This avoids repeated full recipe scans during JEI's clear/fill transaction without changing JEI's item transfer protocol.

Empowered Flux Crystal uses the original USU / SUS / USU pattern with Unstable Bars and Stable Bars, producing two crystals. It restores eight times the normal stability, capped at machine capacity. Full-bar recovery waits until 25% stability or less so it can trigger before the machine fails at zero. Other recovery amounts retain their normal no-waste threshold. Refiners and extractors accept either crystal. Existing recipes and ordinary Flux Crystals remain unchanged.

Recipe and item model are generated by the existing datagen providers.
